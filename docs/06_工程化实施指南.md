## 六、脚手架与环境规范

- Git 仓库 `konban/`，首次 commit 含 `pyproject.toml`、`.env.example`、`.gitignore`、`README.md`、`AGENTS.md`。
- FastAPI 应用可 `uvicorn` 启动：`/health` 健康检查、Pydantic Settings 加载 `.env`、结构化日志（带 `trace_id` 中间件雏形）、目录分层。
- 环境变量：教师统一提供 ASR/TTS key 与 SDK 样例、DeepSeek/Qwen key、coturn TURN server。

## 八、Docker Compose

- `docker compose up` 同时起：`postgres+pgvector`、`redis`、`backend`、`frontend`（vite build 后 nginx 托管）、`Laya 服务`、`MCP servers`。
- 本机 HTTPS（自签或 mkcert）可访问；健康检查通过；具备回滚能力。

## 九、CI 门禁（eval_gate）

- `eval_gate.py` 接 git pre-push hook（本地即可，不要求真 CI 服务器），评测阈值不达标阻断推送。

## 十、可观测三支柱 + Langfuse + 成本

- **Metrics**：`/metrics` 暴露请求量、延迟、分层命中率、S1 闭环率、token 消耗。
- **Logs**：结构化、带 `trace_id`。
- **Traces**：`thread_id` 串起规则→Laya→主控 Agent→Tool→TTS。
- **Langfuse**：docker 起 Langfuse，trace 导入，界面看完整调用链与评估。
- **成本数据**：S1 闭环率 ≥60%、单会话 Tool ≤8、prompt cache 命中率、分层记忆省 Token，写入 README。
