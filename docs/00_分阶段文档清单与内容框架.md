## 二、业务边界基准清单（第五章唯一口径，全流程强制引用）

> 以下 11 条**逐字对齐**《康伴3D数字人_大纲.md》第五章<五、业务边界>。编号 `B1–B11` 作为跨文档追踪标识，各阶段文档以「业务边界约束」章节声明对本清单的遵守情况，不得改写语义。

| 编号 | 边界（非目标） | 原文约束要点 | 可执行化判定 |
| --- | --- | --- | --- |
| **B1** | 不做医疗诊断 | 数字人只记录和提醒，绝不说"您这是高血压" | 输出话术中不得出现诊断结论；异常值统一走"建议问医生"话术并告警人工 |
| **B2** | 不替代 SOS 紧急呼叫 | 红色按钮直连护士站，不承担急救责任 | 系统不承接急救链路；急症命中只告警，不做急救引导 |
| **B3** | 不做高精度 3D 建模和动捕 | 现成 VRM 模型 + 文本驱动口型，不写图形学 | 前端仅加载现成 VRM 与 viseme 口型，禁止建模/动捕模块 |
| **B4** | 不做 AI 歌曲生成/演唱 | 删除 yue2，娱乐只走已授权戏曲和老电影片库 | 无任何音乐生成/演唱模型或模块 |
| **B5** | 不依赖商业 Jev API | System One 用开源 Chinese-Jev / Laya 本地部署，敏感语音文本不外发第三方付费推理 API | 快决策层本地推理；敏感文本不得离开本机/内网 |
| **B6** | 不做盗版曲库/影库 | 仅教学模拟数据、已授权片段或公有领域老影片；教师提供 20–30 条脱敏样例 | 素材库 `copyright_status` 全部为"授权/公有领域/教学模拟"，禁止爬取 |
| **B7** | 不接支付、采购、门禁等物业系统 | 不集成物业系统 | 外部依赖仅限：微信推送、医院 HIS/护工工单（教学 mock） |
| **B8** | 不存完整病历和原始录音 | 只存结构化摘要和脱敏文本；原始音频 72 小时自动删除 | 数据表不含完整病历/原始音频；音频 72h TTL 定时清理 |
| **B9** | 不做移动端原生 App | 家属侧只做最简 H5，不引前端框架 | 家属端为无框架 H5 页面 |
| **B10** | 不做多租户 SaaS 平台 | MVP 单社区部署 | 单社区单实例部署，无租户隔离抽象 |
| **B11** | 不做完整 diarization | 重叠语音时主动询问"谁在说话"，不硬猜 | 无多人分离模块；重叠检测触发主动澄清话术 |
