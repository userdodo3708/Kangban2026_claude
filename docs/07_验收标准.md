## 五、功能验收（承接大纲 11.1）

- [ ] 长者喊唤醒词后 ≤1.5s 得到语音回应。
- [ ] System One 对简单意图（查天气/听戏/查用药）≤200ms 完成分类并直接路由，不调大模型；≥60% 请求在快决策层闭环。
- [ ] 敏感意图（急症/跌倒/情绪低落）被拦截并直接转护工告警，不送入大模型。
- [ ] 置信度 <0.85 自动升级到 System 2，不"硬猜"。
- [ ] 单人间身份识别 100%（设备绑定），双人间有主动确认兜底。
- [ ] 用药提醒能外呼、能口头确认、漏服能派工单。
- [ ] 健康采集输出结构化字段，异常值触发告警。
- [ ] 听戏曲按剧种/剧目检索播放，支持"换一段""大声点"。
- [ ] 看老电影按年代/题材推荐，流畅播放，退出记录时长。
- [ ] 娱乐点播严格来自授权/教学曲库，无未授权资源（B6）。
- [ ] 长期记忆跨会话生效，按 elder_id 隔离。
- [ ] 护工/医生/家属/管理员看到的数据符合权限矩阵。

## 六、工程验收（承接大纲 11.2）

- [ ] 所有 Tool 有独立单元测试，权限场景（伪造身份/跨人访问）100% 覆盖。
- [ ] 20 个固定场景测试集，对话质量回归有基线报告。
- [ ] Docker Compose 一键启动，HTTPS 可访问，健康检查通过。
- [ ] Trace 日志记录每次对话的 identity_source、置信度、Tool 调用和耗时。
- [ ] 原始音频 72h 自动删除，声纹 embedding 加密存储。
- [ ] 至少完成一次回滚演练。
- [ ] 评测闭环：`eval_gate.py` CI 门禁通过；评测报告含基线、测量方式、样本量（可复算）。
- [ ] 可观测三支柱：Metrics（成功率/延迟/成本/闭环率）+ Logs（结构化、trace_id）+ Traces（全链路）；SLO 告警规则配置完成。
- [ ] 安全测试：注入测试集 10+ 条 100% 拦截；越权攻击 100% 拦截；输出脱敏验证通过。
- [ ] 成本数据：S1 闭环率、缓存命中、单会话 Token 预算有测量记录。

## 八、验收评审流程

1. **自检**：各责任主体逐条勾选本清单，标注通过/不通过及证据。
2. **边界终检**：第四节 B1–B11 一票否决，任一不通过即退回。
3. **交叉评审**：产品/技术/安全/测试四角色交叉核对勾选结论。
4. **演示验收**：5 分钟完整场景视频 + 当场查一次完整 Trace。
5. **签字放行**：全体签字，输出验收结论与遗留问题清单。
